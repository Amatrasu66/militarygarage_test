## 1. Priority Classification Framework

- **P0 — Critical (Blocker):** Issues that prevent the website from being trusted, legally compliant, usable, or accurately representing the genuine MCS business model. Must be resolved before any public release.
- **P1 — High:** Issues that substantially impair usability, responsive experience, production architecture, accessibility, or core marketing workflows.
- **P2 — Medium:** Issues affecting visual polish, design system token fidelity, component ergonomics, and secondary interactions.
- **P3 — Low:** Minor cosmetic refinements, micro-copy adjustments, and subtle alignment tweaks.
